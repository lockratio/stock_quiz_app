# BOURSE · market-recall quiz

A mobile-first stock-market quiz app. Plain ES modules, **no build step**, deploys
by pushing to GitHub Pages. Live target: `https://lockratio.github.io/stock_quiz_app/`.

## Run locally

No server is needed to *deploy*, but ES modules + `fetch` need HTTP to run locally
(opening `index.html` as a `file://` won't work):

```bash
python tools/serve.py 8777      # http://127.0.0.1:8777/  (no-cache, HTTP/1.1)
```

## Deploy (GitHub Pages)

Everything in this folder is the site root. Push it to the repo root of
`lockratio/stock_quiz_app` (the Pages site serves at `/stock_quiz_app/`). All paths
are **relative** (`./…`), so the subpath just works. See "Publishing" below.

## Architecture

```
index.html            shell: all screens + links to styles/ and src/main.js
vendor/papaparse.min.js   CSV parser (MIT, vendored — no CDN at runtime)
data/                 generated by tools/build_data.py (see below)
  reference.json        small, instant-load: taxonomy + country/flag/currency + quickview
  universe.csv          big, lazy-load: one row per stock, cleaned + derived
styles/               tokens · base · components · screens · additions (ported from sketch)
src/
  main.js             app controller: state, session lifecycle, keyboard, boot
  state/  store.js persistence.js       central state on a swappable storage adapter
  data/   loader.js schema.js query.js  fetch + coerce + dynamic selectors
  lib/    dom.js fuzzy.js icons.js fx.js
  modes/  registry.js leaderboard.js facts.js idcard.js flashcards.js descriptions.js
  ui/     home.js config.js runner.js summary.js stats.js settings.js
tools/  build_data.py serve.py
```

### Data pipeline (`tools/build_data.py`)

**All app data comes from CSVs — nothing is hard-coded.** The pipeline reads the two
`company_descriptions_*` files (source of truth) from `Bank_DATABASE`, then:

- cleans market caps (` $6,793,285.08 ` → number) and `bm_weight` (`11.12%` → number);
- derives `gsector` / `gindustry` from the `GICS` code (per the project's R maps);
- normalises country display names, attaches ISO-2 flag + region + currency;
- **stacks both indices into one master table** (`universe.csv`, QAID unique, 2,166 rows),
  keeping `IndexCode` so they can be split again;
- emits a compact `reference.json` (taxonomy, countries, quickview top-N lists).

The old `largest_*.csv` files are **not shipped** — leaderboards and every "top N in X"
filter are computed live in `src/data/query.js`, which enables the richer, dynamic
questions and filters. Re-run any time the source CSVs change:

```bash
python tools/build_data.py
```

### Persistence

`src/state/persistence.js` is a thin localStorage adapter (`get/set/merge/remove/list`
+ export/import). Swapping in a remote backend (Supabase, etc.) is a one-file change.
**Stats live in one browser only** — phone ↔ desktop don't sync; use Settings →
Export / Import to move them. This limitation is surfaced in the Settings screen.

## Modes

1. **Leaderboard Guess** — one type-in box; name the top-N by cap in a sector / region /
   industry / country. Fuzzy on name *and* ticker; partial credit (found / list size).
2. **Universe Facts** — currencies, sector↔industry map, GICS codes, exchanges, regions.
3. **Stock Universe** — from a (large) ticker, recall company / industry / country / cap.
4. **Business Descriptions** — searchable/filterable browser + sectioned detail sheet;
   Guess mode is a filterable blind-shuffle of the same cards.
5. **Custom Flashcards** — pick any column as front, one or more as back; 3-D flip.

Answer styles (multiple-choice / true-false / type-in / flashcard) share one green/red
feedback treatment. Keyboard is minimal and never hijacks typing (Enter submits/advances,
Alt+←/→ move between questions); Hint / Flag / Skip are on-card buttons.
